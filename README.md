## Variáveis de ambiente

Para rodar este projeto localmente, você precisa criar um arquivo `.env` na raiz do projeto com a seguinte variável:

VITE_NEWS_API_KEY=sua_chave_aqui

Para obter sua chave gratuita, acesse [https://newsapi.org](https://newsapi.org) e crie uma conta.
